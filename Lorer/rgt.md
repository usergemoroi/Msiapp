# Lorer Module

## Структура папки

```
/Lorer/
├── lorer.exe              ← Главный загрузчик
├── Standoff2Core.dll      ← Ядро модуля
└── rgt.md                 ← Этот файл
```

## Описание файлов

### lorer.exe
Главный загрузчик модуля Lorer для Standoff 2.

### Standoff2Core.dll
Ядро модуля, содержащее основную логику работы с игрой.

### rgt.md
Документация по структуре и назначению файлов модуля.
