2.1. Анализ памяти целевого приложения (Standoff 2 v0.37.0)

В результате анализа dump.cs были выявлены следующие офсеты для версии 0.37.0:

| Класс / Поле | Офсет | Описание |
|---|---|---|
| GameManager (Static Instance) | 0x18 | Указатель на экземпляр в статических полях |
| PlayerManager (Static Instance) | 0x10-0x18 | Указатель в LazySingleton |
| PlayerManager -> LocalPlayer | 0x68 | Поле <FDBAECBCFCHCAAE>k__BackingField |
| PlayerManager -> PlayerList | 0x38 | Поле HAHCFEHECFEDHHC (HashSet) |
| PlayerController -> Health | 0x150 | Поле <GBGDAFDAABGEDCB>k__BackingField |
| PlayerController -> Team | 0x154 | Поле <BGFGGFFCADDEFCE>k__BackingField |
| PlayerController -> MovementController | 0x98 | Поле <ECAFDHEFEDHFDAB>k__BackingField |
| MovementController -> TranslationData | 0xB0 | Поле translationData |
| TranslationData -> Position | 0x1C | Поле BFCAFBAGDCBGHHB (Vector3) |

Цепочка для получения позиции игрока:
PlayerController + 0x98 (MovementController) -> + 0xB0 (TranslationData) -> + 0x1C (Vector3 Position)
